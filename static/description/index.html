Key Features

⚙ Reusable Profiles

Save and reuse import/export configurations. Define the target Odoo model, file format, field mapping, and transformations once — run them as many times as you need.

🔄 Field Mapping

Map source file columns to Odoo fields with a visual editor. Supports relational fields, computed defaults, and conditional mapping rules.

🔨 Data Transformations

Transform values on the fly: type casting, value mapping tables, Python expressions, regex find/replace, date reformatting, and custom sanitisers.

⚡ Batch Processing

Process thousands of records efficiently with configurable batch sizes. Real-time progress tracking shows records processed, created, updated, and any errors encountered.

🕓 Scheduling

Attach profiles to Odoo scheduled actions (ir.cron) for fully automated recurring imports and exports — no manual intervention required.

📈 OWL Dashboard

Monitor all migration activity from a single dashboard. View execution statistics, success/failure rates, recent operations, and quick-launch your most-used profiles.

🔎 Dry-Run & Preview

Run any import in preview mode to validate data before committing. See exactly what would be created, updated, or skipped — with detailed error reporting.

↺ Rollback Support

Every imported record is tracked via external IDs. If something goes wrong, roll back an entire import operation with one click to restore the previous state.

ERP Migration

Technical Details

Dependencies

  • Odoo modules: base, web, mail
  • Python: openpyxl (Excel read/write)
  • CSV, XML, JSON, SQLite — Python standard library (no extra packages)
  • ODS support via built-in XML parsing (no extra packages)

Compatibility

  • Odoo version: 19.0 Community Edition
  • Python: 3.10+
  • License: LGPL-3
  • Multi-company: fully supported

Security

Access is controlled by two groups: Migrate User (run imports/exports, view own operations) and Migrate Manager (create/edit profiles, manage templates, view all operations). Record rules enforce multi-company isolation.
